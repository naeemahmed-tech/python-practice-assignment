# Python Practice Assignment

This repository contains the two Python practice problems.

## Files

- `personal_calculator.py` — collects personal information and two numbers, then displays addition, subtraction, multiplication, and division.
- `grade_calculator.py` — calculates the average of three subject marks and determines the grade.

## Requirements

- Python 3

## How to run

Open a terminal in this folder and run:

```bash
python personal_calculator.py
```

```bash
python grade_calculator.py
```

On some systems, use `python3` instead of `python`.

## Grade scale

| Average marks | Grade |
|---|---|
| 80–100 | A+ |
| 70–79 | A |
| 60–69 | A- |
| 50–59 | B |
| 40–49 | C |
| Below 40 | F |

The grade calculator rejects any subject mark below 0 or above 100.
